# 🤖 Llama3 Local Chatbot with Invisible Web Navigation & Electron Desktop

This is an Artificial Intelligence chatbot that runs **100% locally** using **Node.js (Express)** and the **Llama3** model (via Ollama). 

This project can be run as a standard local web server or as a **native desktop application using Electron**, offering a clean, direct user interface without external cloud dependencies. Its main superpower is **native, real-time web page reading and analysis**, resolving the isolation of local AI models without complex plugins.

---

## 🚀 Main Superpower: Native Internet Connection (Invisible Fetch)

Unlike traditional local models that are completely isolated from the outside world, this chatbot features an **intelligent URL interceptor** integrated directly into the backend (`index.js`).

* **How does it work?** The Express server invisibly monitors every message you send. If it detects a valid link (e.g., `https://bonsecours66.com/`), it uses the `axios` library to download the page in the background within milliseconds, strips out all unnecessary junk (JavaScript blocks, CSS styles, HTML tags, ads), and injects the clean text directly into Llama3's memory along with your original request.
* **What can you do with this?**
    * Ask for executive summaries of lengthy articles, newspaper stories, or blog posts.
    * Perform "conversational web scraping" (e.g., "Find the contact details, address, and hours on this website https://example.com").
    * Analyze source code or technical documentation hosted on public repository links.
    * Translate or analyze the content of foreign web pages into the language of your choice.

*(Note: Since it works through plaintext reading at the server level, it cannot access private pages that require a prior login or that have highly aggressive automated security walls like Captchas).*

---

## 📦 Other Included Features

* **💾 Local Persistence and Autosaves:** Every time the AI responds, the system creates a chronological save in the `autosaves/` folder (with an automatic rolling limit of 30 files). You can also manually save your chats in `JSON` format or in clean `Markdown (.md)`.
* **✏️ In-Place Message Editing:** Hovering over a user message reveals a pencil icon. You can correct your prompt; the system will intelligently trim the history up to that exact point and automatically relaunch the request.
* **🔥 Memory Control (Tokens):** Displays how many tokens of Llama3's maximum context (8192 tokens) you have consumed in the active session using the `gpt-3-encoder` library, preventing the AI from forgetting previous messages.
* **🌍 Multi-language and Real-Time:** Interactive UI selector for Spanish, English, and French that dynamically modifies the `System Prompt`. It also automatically injects your computer's exact date and time.

## 🛠️ Prerequisites

1. **Node.js** (Version 16 or higher installed on your PC/Mac).
2. **Ollama** running in the background with the `llama3` model downloaded.

---

## ⚙️ Installation and Quick Start

1. Open your command terminal in the root folder of the project:
   cd /path/to/your/folder/chatbotWeb

2. Install the required Node.js dependencies:
   npm install express axios gpt-3-encoder

3. **To run it as a Web App:**
   node index.js
   Then, open your favorite web browser and go to `http://localhost:3000`.

4. **To run it as a Desktop App (Electron):**
   Make sure you have Electron dependencies installed, then run the initialization command defined in your package.json script (usually `npm start` or running Electron targeting the `electron/main.js` file).
